# MacGuard

브라우저에서 PIN 잠금 화면을 표시하고, 입력·탭 전환·네트워크·충전 상태 변화 등에 반응해 경보와 기록을 남기는 웹 앱입니다. 카메라 촬영과 위치 표시, PWA용 설정을 포함합니다.

**MacGuard의 잠금은 웹 페이지 안에서 동작합니다.** macOS 로그인 잠금이나 운영체제 권한 제어를 대체하지 않으며, 브라우저 종료·강제 종료·기기 절전 후에도 보호가 유지되는 보안 제품은 아닙니다.

## 주요 기능

- 최초 실행 시 6자리 PIN 등록, PIN 변경 및 잠금 해제
- 잘못된 PIN 반복 입력, 잠금 중 비허용 키·클릭·스크롤 등에 대한 경보
- 설정에 따른 화면 비활성화, 크기 변경, 온라인·오프라인, 충전 상태 변경 감지
- Web Audio 기반 경보음과 내장 오디오 재생
- 카메라 권한을 사용한 이벤트 사진 촬영과 미리보기
- 브라우저 위치 정보 또는 IP 기반 위치 표시
- 보안 이벤트 로그, 통계, `change.log` 다운로드
- Web App Manifest와 Service Worker를 이용한 PWA 기반 구성

## 사용 기술

| 기술 | 용도 |
| --- | --- |
| HTML / CSS / Vanilla JavaScript | 대시보드, PIN UI, 상태·이벤트 관리 |
| Web Audio API | 경보음과 피드백 음향 |
| MediaDevices / Canvas 2D | 카메라 영상과 JPEG 캡처 |
| Geolocation API | 위치 권한을 통한 좌표 조회 |
| Fetch / ipapi.co | 위치 권한을 쓸 수 없을 때 IP 기반 위치 조회 |
| Battery Status API | 지원 브라우저의 충전 상태 변경 감지 |
| Page Visibility / DOM 이벤트 | 탭 비활성화, 입력, 크기 변경 감지 |
| localStorage | PIN, 설정, 카운터, 캡처 사진 저장 |
| Service Worker / Cache API / Manifest | 일부 앱 자산 캐시와 설치용 메타데이터 |

별도 서버 애플리케이션, API 키, 패키지 설치나 빌드는 필요하지 않습니다. 웹 폰트는 Google Fonts에서 로딩합니다.

## 실행 방법

카메라·위치·Service Worker를 사용하려면 **HTTPS 또는 localhost**에서 실행하세요. GitHub의 **Code → Download ZIP**으로 내려받은 경우 압축을 푼 폴더에서 로컬 서버를 시작하면 됩니다.

Git과 Python 3가 설치되어 있다면:

```sh
git clone https://github.com/Velvitty/MacGuard.git
cd MacGuard
python3 -m http.server 8000 --bind 127.0.0.1
```

- 프로그램: <http://localhost:8000/index.html>
- 소개·사용 안내: <http://localhost:8000/howto.html>

지원 브라우저에서는 설치 기능으로 독립 창 형태로 실행할 수 있습니다. 실제 PWA 설치 가능 여부와 각 API 지원 여부는 브라우저에 따라 달라집니다.

## 사용 방법

1. 첫 실행 시 6자리 숫자 PIN을 두 번 입력해 등록합니다.
2. 시작 화면에서 프로그램 또는 설정 화면으로 이동합니다.
3. 필요한 감지 항목을 켭니다. 카메라 촬영과 위치 기능을 사용할 경우 브라우저 권한 요청을 허용합니다.
4. 기기 볼륨과 오디오 재생 상태를 확인한 뒤 잠금을 실행합니다. 카운트다운이 끝나면 잠금 화면으로 전환됩니다.
5. 잠금을 해제하려면 등록한 PIN을 입력합니다. 경보가 발생한 경우에도 경보 해제 화면에서 PIN을 입력합니다.
6. 대시보드에서 발생 기록과 캡처 이미지를 확인하고 필요한 로그를 저장합니다.

## 감지 기능의 범위

| 항목 | 현재 동작 및 조건 |
| --- | --- |
| PIN 오류 | 잠금 해제 PIN을 3회 이상 틀리면 경보 |
| 키·마우스 입력 | 잠금 중 비허용 키, 클릭, 스크롤 등에 반응 |
| 탭·창 상태 | 설정과 브라우저 이벤트 전달 여부에 따라 감지 |
| 네트워크 | 브라우저의 `online` / `offline` 전환 감지. 특정 Wi-Fi 장비 감시는 아님 |
| 충전 상태 | `navigator.getBattery()` 지원 시 충전 상태 변경 감지 |
| 닫기 시도 | `beforeunload` 기반 확인 요청. 종료를 강제로 막을 수는 없음 |
| 카메라 | 권한과 사용 가능한 카메라가 있어야 촬영 가능 |
| 위치 | 브라우저 위치 조회, 실패하거나 비활성화된 경우 IP 위치 조회 |

## 저장소 구성

```text
.
├── index.html            # 앱 UI, 경보·PIN·카메라·위치·로그 로직
├── howto.html            # 소개와 사용 안내
├── manifest.json         # PWA 이름·시작 경로·아이콘 설정
├── sw.js                 # 앱 자산 캐시
├── icons/
│   ├── icon-192x192.png
│   └── icon-512x512.png
└── README.md
```

주요 함수는 `tryUnlock()`·`lockNow()`의 잠금 처리, `triggerSecurityAlert()`의 경보 처리, `initCamera()`·`captureIntruder()`의 촬영, `fetchLocation()`·`ipLocation()`의 위치 조회, `addLog()`·`saveChangeLog()`의 기록 관리입니다.

## 데이터 저장과 외부 통신

- PIN은 암호화 없이 현재 사이트의 `localStorage`에 저장됩니다. 운영체제 비밀번호나 다른 서비스 비밀번호를 재사용하지 마세요.
- 설정, 경보·실패·촬영 카운터와 최근 캡처 사진도 브라우저에 저장됩니다. 캡처 목록은 메모리에서 최대 20장, 영구 저장에서는 최근 10장으로 제한됩니다.
- 이벤트 로그는 실행 중 메모리에 쌓입니다. 보관할 기록은 다운로드하세요. 브라우저 데이터 삭제 시 저장된 PIN과 설정·사진도 사라질 수 있습니다.
- IP 위치 조회는 `https://ipapi.co/json/`에 요청합니다. 위치 토글을 끄더라도 현재 구현은 IP 조회로 전환할 수 있습니다.
- 앱 자체에 사진·로그를 원격 서버로 전송하는 구현은 없으며, 이메일 알림 함수는 비어 있어 실제 이메일을 보내지 않습니다.

## 알려진 제한과 문제 해결

- 카메라가 동작하지 않으면 HTTPS/localhost 여부와 사이트 권한을 확인하세요.
- 충전 감지가 되지 않으면 사용 중인 브라우저가 Battery Status API를 지원하는지 확인하세요. 모든 macOS 브라우저에서 동작하지는 않습니다.
- 브라우저가 백그라운드로 전환되거나 기기가 절전 상태가 되면 경보·감지 실행이 제한될 수 있습니다.
- Service Worker가 미리 캐시하는 파일은 `index.html`과 `manifest.json`입니다. 안내 페이지·아이콘·외부 폰트까지 포함한 완전한 오프라인 동작을 보장하지 않습니다.
- 업데이트가 반영되지 않을 때는 해당 사이트의 캐시와 Service Worker 상태를 확인하세요. 사이트 데이터를 지우면 PIN·설정·사진도 함께 지워질 수 있습니다.
- 소개 페이지의 표현과 기능 지원 범위가 다를 수 있으므로 실제 동작은 위 조건을 기준으로 확인하세요.
