# MacGuard

브라우저에서 PIN 잠금 화면을 표시하고, 입력·탭 전환·네트워크·충전 상태 변화 등에 반응해 경보와 기록을 남기는 웹 앱입니다. 카메라 촬영과 위치 표시, PWA용 설정을 포함합니다.

**MacGuard의 잠금은 웹 페이지 안에서 동작합니다.** macOS 로그인 잠금이나 운영체제 권한 제어를 대체하지 않으며, 브라우저 종료·강제 종료·기기 절전 후에도 보호가 유지되는 보안 제품은 아닙니다.

## 주요 기능

- 최초 실행 시 6자리 PIN 등록, PIN 변경 및 잠금 해제
- 잘못된 PIN 반복 입력, 잠금 중 비허용 키·클릭·스크롤 등에 대한 경보
- 설정에 따른 화면 비활성화, 크기 변경, 온라인·오프라인, 충전 상태 변경 감지
- Web Audio 기반 경보음과 내장 오디오 재생
- 카메라 권한을 사용한 이벤트 사진 촬영과 미리보기
- 브라우저 위치 정보 또는 IP 기반 위치 표시
- 보안 이벤트 로그, 통계, `change.log` 다운로드
- Web App Manifest와 Service Worker를 이용한 PWA 기반 구성

## 사용 기술

| 기술 | 용도 |
| --- | --- |
| HTML / CSS / Vanilla JavaScript | 대시보드, PIN UI, 상태·이벤트 관리 |
| Web Audio API | 경보음과 피드백 음향 |
| MediaDevices / Canvas 2D | 카메라 영상과 JPEG 캡처 |
| Geolocation API | 위치 권한을 통한 좌표 조회 |
| Fetch / ipapi.co | 위치 권한을 쓸 수 없을 때 IP 기반 위치 조회 |
| Battery Status API | 지원 브라우저의 충전 상태 변경 감지 |
| Page Visibility / DOM 이벤트 | 탭 비활성화, 입력, 크기 변경 감지 |
| localStorage | PIN, 설정, 카운터, 캡처 사진 저장 |
| Service Worker / Cache API / Manifest | 일부 앱 자산 캐시와 설치용 메타데이터 |

별도 서버 애플리케이션, API 키, 패키지 설치나 빌드는 필요하지 않습니다. 웹 폰트는 Google Fonts에서 로딩합니다.

## 실행 방법

카메라·위치·Service Worker를 사용하려면 **HTTPS 또는 localhost**에서 실행하세요. GitHub의 **Code → Download ZIP**으로 내려받은 경우 압축을 푼 폴더에서 로컬 서버를 시작하면 됩니다.

Git과 Python 3가 설치되어 있다면:

```sh
git clone https://github.com/Velvitty/MacGuard.git
cd MacGuard
python3 -m http.server 8000 --bind 127.0.0.1
```

- 프로그램: <http://localhost:8000/index.html>
- 소개·사용 안내: <http://localhost:8000/howto.html>

지원 브라우저에서는 설치 기능으로 독립 창 형태로 실행할 수 있습니다. 실제 PWA 설치 가능 여부와 각 API 지원 여부는 브라우저에 따라 달라집니다.

## 사용 방법

1. 첫 실행 시 6자리 숫자 PIN을 두 번 입력해 등록합니다.
2. 시작 화면에서 프로그램 또는 설정 화면으로 이동합니다.
3. 필요한 감지 항목을 켭니다. 카메라 촬영과 위치 기능을 사용할 경우 브라우저 권한 요청을 허용합니다.
4. 기기 볼륨과 오디오 재생 상태를 확인한 뒤 잠금을 실행합니다. 카운트다운이 끝나면 잠금 화면으로 전환됩니다.
5. 잠금을 해제하려면 등록한 PIN을 입력합니다. 경보가 발생한 경우에도 경보 해제 화면에서 PIN을 입력합니다.
6. 대시보드에서 발생 기록과 캡처 이미지를 확인하고 필요한 로그를 저장합니다.

## 감지 기능의 범위

| 항목 | 현재 동작 및 조건 |
| --- | --- |
| PIN 오류 | 잠금 해제 PIN을 3회 이상 틀리면 경보 |
| 키·마우스 입력 | 잠금 중 비허용 키, 클릭, 스크롤 등에 반응 |
| 탭·창 상태 | 설정과 브라우저 이벤트 전달 여부에 따라 감지 |
| 네트워크 | 브라우저의 `online` / `offline` 전환 감지. 특정 Wi-Fi 장비 감시는 아님 |
| 충전 상태 | `navigator.getBattery()` 지원 시 충전 상태 변경 감지 |
| 닫기 시도 | `beforeunload` 기반 확인 요청. 종료를 강제로 막을 수는 없음 |
| 카메라 | 권한과 사용 가능한 카메라가 있어야 촬영 가능 |
| 위치 | 브라우저 위치 조회, 실패하거나 비활성화된 경우 IP 위치 조회 |

## 저장소 구성

```text
.
├── index.html            # 앱 UI, 경보·PIN·카메라·위치·로그 로직
├── howto.html            # 소개와 사용 안내
├── manifest.json         # PWA 이름·시작 경로·아이콘 설정
├── sw.js                 # 앱 자산 캐시
├── icons/
│   ├── icon-192x192.png
│   └── icon-512x512.png
└── README.md
```

주요 함수는 `tryUnlock()`·`lockNow()`의 잠금 처리, `triggerSecurityAlert()`의 경보 처리, `initCamera()`·`captureIntruder()`의 촬영, `fetchLocation()`·`ipLocation()`의 위치 조회, `addLog()`·`saveChangeLog()`의 기록 관리입니다.

## 상세 사양과 구성요소

| 구성요소 | 구현과 책임 |
| --- | --- |
| 화면·상태 제어 | `state.isLocked`, `state.introActive`, 각 오버레이의 CSS 클래스로 인트로·대시보드·잠금·경보 표시 관리 |
| PIN | 최초 등록, 변경, 잠금 해제, 경보 해제의 입력 UI와 비교 함수 |
| 감지기 | DOM 이벤트, 배터리·네트워크 변화 → `triggerSecurityAlert(reason)` 호출 |
| 경보 오디오 | Web Audio의 Oscillator → WaveShaper → Gain 경로와 내장 MP3 재생 |
| 카메라 | `<video>` 스트림 → 숨겨진 `<canvas>` → JPEG Data URL |
| 위치 | `getCurrentPosition()`의 1회 조회 → 실패 시 `ipLocation()` |
| 로그 | `addLog()` → 화면 목록과 메모리의 `changeLog` 배열, `saveChangeLog()` 다운로드 |
| PWA | `manifest.json`의 설치 정보와 `sw.js`의 정적 파일 캐시 |

앱 UI·CSS·이벤트 처리·오디오·저장 로직은 `index.html`에 함께 있습니다. 서버 인증, 계정 관리, 원격 제어용 API, 데이터베이스는 구현되어 있지 않습니다.

## 기술 문서: 상태 전이와 PIN 정책

| 상태 | 진입·전환 조건 | 감지 동작 |
| --- | --- | --- |
| 시작 화면 | `init()` 후 `introActive = true`. PIN이 없으면 최초 등록 모달 표시 | 일반 감지 이벤트는 인트로 조건에서 반환 |
| 대시보드 | 설정 화면 진입 또는 잠금 PIN 일치. `isLocked = false` | 잠금 전용 감지는 중단, 설정·로그·사진 확인 가능 |
| 잠금 준비 | `lockNow()`의 숫자 연출과 카운트다운 | 키 입력 차단. 카운트다운 차단막이 활성화된 동안 경보 함수는 즉시 반환 |
| 잠금 | 카운트다운 완료 후 `isLocked = true`, 잠금 화면 표시 | 각 토글과 이벤트별 조건에 따라 경보 발생 |
| 경보 표시 | `triggerSecurityAlert()`가 오버레이를 열고 경보음 재생 | 잠금 상태와 별도로 관리. 새 이벤트가 오면 경보 횟수·표시 내용 갱신 가능 |
| 경보 해제 | `dismissAlert()`에서 PIN 일치 | 경보창과 소리만 해제. 잠금 해제는 `tryUnlock()`의 별도 PIN 확인 필요 |

`lockNowFast()`라는 즉시 잠금 함수도 있지만, 실제 화면 버튼·시작 흐름은 `lockNow()`를 호출합니다. 카운트다운은 여러 화면 전환을 포함하므로 표시 숫자를 정확한 잠금 준비 시간으로 간주하지 마세요.

- PIN UI는 숫자만 남기고 최대 6자리로 제한합니다. 최초 등록은 6자리 두 입력이 같아야 완료됩니다.
- 잠금 화면은 숫자 6자리 입력 시 확인하며 Enter로도 확인합니다. 비어 있지 않은 잘못된 입력은 실패로 집계됩니다.
- `failCount`는 현재 실행 중 잠금 해제 실패 횟수이고, 정상 잠금 해제 시 0으로 돌아갑니다. 3회 이상이면 `WRONG_PIN` 경보가 발생합니다.
- `tog_wrongpass`는 짧은 오답 피드백음을 제어합니다. **3회 실패 경보 자체를 비활성화하는 스위치는 아닙니다.**
- PIN 변경은 현재 PIN 확인, 새 PIN 6자리, 확인값 일치, 기존 PIN과 다름을 검사합니다. 현재 PIN 확인 3회 실패 시 경보와 잠금 전환을 수행합니다.
- 경보 해제 PIN 오류는 경고음·로그를 남기지만 `failCount`와 누적 `mg_fails`를 증가시키지 않습니다. 서버 측 잠금이나 재시도 지연은 없습니다.

## 기술 문서: 이벤트 조건과 기본 설정

일반적인 잠금 이벤트는 `isLocked = true`이고 `introActive = false`일 때 처리합니다. 토글을 바꾸면 즉시 설정 객체와 `mg_settings`에 반영됩니다.

| 설정 / 이벤트 | 기본값 | 실제 조건과 결과 |
| --- | --- | --- |
| `tog_wrongpass` | 켜짐 | 잘못된 PIN의 짧은 오류음 제어 |
| `tog_capture` | 켜짐 | PIN 오류·충전 변경 등 촬영 호출 지점에서 사진 촬영 허용 |
| `tog_power` | 켜짐 | Battery API의 `chargingchange`. 전원 경보, 촬영 설정 시 캡처 |
| `tog_gps` | 켜짐 | Geolocation 조회 시도. 꺼짐·실패·미지원이면 IP 조회로 전환 |
| `tog_resize` | 꺼짐 | `resize` 이벤트마다 화면 크기 기록과 경보 |
| `tog_blur` | 켜짐 | 숨겨진 탭, 창 포커스 이탈, 마우스 이동·창 이탈 감지 |
| `tog_close` | 켜짐 | `beforeunload`에서 브라우저 이탈 확인 요청 |
| `tog_network` | 켜짐 | `online`·`offline`에서 네트워크 경보 |
| 비허용 키 | 별도 토글 없음 | 숫자와 Backspace·Delete·Tab·좌우 방향키·Home·End·Enter 외 키에 경보 |
| 클릭·스크롤 | 별도 토글 없음 | `mousedown`·`wheel`에 경보. 경보창이 이미 열려 있으면 이 경로는 무시 |

마우스 이동 임계값은 `min(창 너비, 창 높이) × 0.075`입니다. 기준점에서의 직선 이동거리가 이를 넘으면 감지합니다. 마우스 이동·창 이탈 두 감지기는 3초 쿨다운을 공유합니다. 코드 주석의 “15%”와 달리 실제 계산은 **짧은 변의 7.5% 거리**입니다.

`beforeunload`는 이탈 확인을 요청할 뿐, PIN을 확인해야만 브라우저를 종료하도록 강제하지 않습니다. 코드의 `CLOSE`·`KIOSK` 경보 메시지 이름만으로 전체화면 강제 유지나 OS 종료 방지 기능이 제공되는 것은 아닙니다. 현재 `fullscreenchange` 감지나 Fullscreen API 호출은 없습니다.

## 기술 문서: 저장 데이터와 보관 범위

모든 키는 접속한 **사이트의 origin(프로토콜·호스트·포트)**에 속한 `localStorage`에 저장됩니다. 서로 다른 도메인, HTTP/HTTPS 또는 localhost 포트는 저장 공간을 공유하지 않습니다.

| 키 | 저장 형식 | 용도 |
| --- | --- | --- |
| `mg_pin` | 6자리 숫자 문자열 | 평문 PIN |
| `mg_fails` | 정수를 문자열로 저장 | 잠금 해제·PIN 변경에서 누적된 실패 수 |
| `mg_alerts` | 정수를 문자열로 저장 | 경보 함수가 처리한 호출 수 |
| `mg_photos` | 정수를 문자열로 저장 | 누적 촬영 횟수. 현재 보관 사진 수와 다를 수 있음 |
| `mg_settings` | JSON 객체 `{ tog_wrongpass, tog_capture, tog_power, tog_gps, tog_resize, tog_blur, tog_close, tog_network }` | 각 값은 boolean |
| `mg_logcfg` | JSON 객체 | 아래 12개 로그 분류의 기록 여부, 기본값 모두 `true` |
| `mg_capturedPhotos` | JSON 배열 `[{ url, time, reason }]` | 최근 사진의 Data URL·지역화된 시각 문자열·사유 |
| `mg_email` | JSON 객체, 없으면 `{}` | 초기 상태에서 읽는 잔여 설정. 실제 메일 전송에는 사용되지 않음 |

로그 분류 키는 `log_access`, `log_alert`, `log_photo`, `log_pin`, `log_power`, `log_network`, `log_resize`, `log_blur`, `log_close`, `log_location`, `log_sys`, `log_cfg`입니다. 분류를 끄면 해당 로그의 **화면 표시와 다운로드 배열 기록을 함께 건너뛰며**, 감지 기능 자체를 끄지는 않습니다.

카메라 캡처는 영상의 실제 너비·높이를 사용하고 크기를 읽지 못하면 320×240을 사용합니다. 화면을 좌우 반전해 그리고 하단에 사유·시각을 넣은 뒤 JPEG 품질 인자 `0.8`로 인코딩합니다.

- 실행 중 사진 배열: 최근 **최대 20장**.
- 새로고침 후 복원할 영구 저장: 최근 **최대 10장**.
- 대시보드 썸네일: 최근 **최대 6장**. 클릭하면 확대 표시합니다.
- 모든 경보가 사진을 남기지는 않습니다. 촬영은 잘못된 잠금 PIN, 충전 상태 변경, PIN 변경 오류 3회 이상 등 명시적으로 `captureIntruder()`를 호출하는 경로에서 수행합니다.
- 촬영·JSON 저장에 대한 용량 초과 복구가 없어 브라우저 저장 공간이 부족하면 저장이 실패할 수 있습니다.

`addLog()`는 화면에 최신 100개까지만 유지하지만 다운로드용 `changeLog` 배열에는 별도 개수 제한이 없습니다. 내려받는 파일은 UTF-8 `change.log`이며, `[시각] [레벨] [분류] 메시지` 형식입니다. 파일 시각은 `toISOString()`에서 만든 UTC 값이고, 화면 시각은 기기 지역 시간입니다. 파일 표기에는 `Z`가 생략됩니다.

화면의 로그 초기화는 DOM 목록을 지우는 동작으로, 기존 `changeLog` 배열은 비우지 않습니다. 페이지를 다시 열면 메모리 로그는 사라집니다. 두 초기화 함수의 삭제 키도 다릅니다. `resetApp()`은 저장 사진을 지우지만 `confirmResetApp()`은 `mg_capturedPhotos`를 삭제하지 않으므로 초기화 안내 문구만으로 사진 삭제까지 완료되었다고 판단하지 마세요.

| --- | --- |
| 카메라 | 보안 컨텍스트와 카메라 권한. `getUserMedia({ video: true })`, 마이크 요청 없음 |
| 위치 | 보안 컨텍스트·위치 권한·Geolocation 지원. 연속 추적이 아닌 단일 조회 |
| IP 위치 | 외부 `ipapi.co` 연결 필요. 권한이 없거나 GPS 토글이 꺼져도 요청될 수 있음 |
| 경보음 | Web Audio 지원, 사용자 동작 후 오디오 활성화, 기기·탭의 음량 및 재생 허용 |
| 배터리 | `navigator.getBattery`가 있을 때만 감지기 등록 |
| 설치·캐시 | Service Worker·Manifest 지원. HTTPS 또는 localhost에서 실행 |

오디오는 첫 클릭·키 입력·터치에서 무음 버퍼를 재생해 활성화를 시도합니다. 경보 시 하강(1200→200Hz), 공습형(400↔1200Hz), 상승(200→1400Hz), 교번형(600↔900Hz) 사이렌을 순서대로 반복하며 내장 MP3도 함께 반복합니다. PIN 경보 해제 시 예약 타이머와 생성된 오디오 노드를 정지합니다. 기기 볼륨을 강제로 높이거나 음소거를 해제하는 구현은 없습니다.

현재 Service Worker의 캐시 이름은 `macguard-v3`, 사전 캐시 목록은 `./index.html`과 `./manifest.json`입니다.

1. 설치 시 `cache.addAll()`로 두 파일을 저장하고 `skipWaiting()`을 호출합니다.
2. 활성화 시 현재 이름과 다른 캐시를 삭제하고 `clients.claim()`을 호출합니다. 삭제 조건은 이 앱 접두사로 한정되지 않아 같은 origin의 다른 Cache Storage도 영향을 받을 수 있습니다.
3. 요청은 `caches.match()`로 먼저 찾고, 없으면 네트워크에서 가져옵니다. 네트워크 응답을 동적으로 캐시에 추가하지 않습니다.

따라서 안내 페이지·아이콘·폰트·IP 위치 정보의 오프라인 사용과 `/` 경로의 대체 응답은 보장되지 않습니다. 배포 후 HTML을 갱신할 때는 캐시 버전과 Service Worker 갱신도 함께 관리해야 합니다. 캐시 우선 응답이므로 이미 캐시된 `index.html`은 네트워크의 최신 파일보다 먼저 반환됩니다.

Manifest는 시작 경로 `./index.html`, 범위 `.`, 표시 모드 `standalone`, 방향 `landscape`, 192×192·512×512 PNG 아이콘을 선언합니다. 설치된 앱처럼 표시되어도 감지·권한·수명은 브라우저 실행 환경에 따릅니다.

## 데이터 저장과 외부 통신

- PIN은 암호화 없이 현재 사이트의 `localStorage`에 저장됩니다. 운영체제 비밀번호나 다른 서비스 비밀번호를 재사용하지 마세요.
- 설정, 경보·실패·촬영 카운터와 최근 캡처 사진도 브라우저에 저장됩니다. 캡처 목록은 메모리에서 최대 20장, 영구 저장에서는 최근 10장으로 제한됩니다.
- 이벤트 로그는 실행 중 메모리에 쌓입니다. 보관할 기록은 다운로드하세요. 브라우저 데이터 삭제 시 저장된 PIN과 설정·사진도 사라질 수 있습니다.
- IP 위치 조회는 `https://ipapi.co/json/`에 요청합니다. 위치 토글을 끄더라도 현재 구현은 IP 조회로 전환할 수 있습니다.
- 앱 자체에 사진·로그를 원격 서버로 전송하는 구현은 없으며, 이메일 알림 함수는 비어 있어 실제 이메일을 보내지 않습니다.

## 보안 경계

이 앱은 같은 브라우저의 JavaScript와 DOM으로 잠금 화면을 표현합니다. 개발자 도구나 사이트 데이터 접근을 막는 인증 경계가 없고 PIN 해시·서버 검증·변조 방지 로그도 없습니다. 새로고침 후 시작 화면의 **설정 화면으로** 경로는 저장된 PIN을 다시 인증하지 않고 대시보드로 이동하므로 지속적인 접근 통제 수단으로 사용할 수 없습니다.

카메라 설정을 끄는 처리는 이후 촬영·초기화 호출을 제어하지만, 이미 열린 미디어 트랙을 `stop()`하는 코드는 없습니다. 카메라 접근을 확실히 종료하려면 페이지를 닫거나 브라우저 사이트 권한을 해제하세요. 백그라운드·절전·탭 종료 뒤의 감지나 녹화 유지, 기기 이동 센서 감지, 원격 분실 추적은 구현되어 있지 않습니다.

## 알려진 제한과 문제 해결

- 카메라가 동작하지 않으면 HTTPS/localhost 여부와 사이트 권한을 확인하세요.
- 충전 감지가 되지 않으면 사용 중인 브라우저가 Battery Status API를 지원하는지 확인하세요. 모든 macOS 브라우저에서 동작하지는 않습니다.
- 브라우저가 백그라운드로 전환되거나 기기가 절전 상태가 되면 경보·감지 실행이 제한될 수 있습니다.
- Service Worker가 미리 캐시하는 파일은 `index.html`과 `manifest.json`입니다. 안내 페이지·아이콘·외부 폰트까지 포함한 완전한 오프라인 동작을 보장하지 않습니다.
- 업데이트가 반영되지 않을 때는 해당 사이트의 캐시와 Service Worker 상태를 확인하세요. 사이트 데이터를 지우면 PIN·설정·사진도 함께 지워질 수 있습니다.
- 소개 페이지의 표현과 기능 지원 범위가 다를 수 있으므로 실제 동작은 위 조건을 기준으로 확인하세요.
